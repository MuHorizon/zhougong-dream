# 《周公解梦》结构化整理规则

输入字段：

- id
- category
- sourceText
- suggestions

必须输出：

- id
- symbols
- situation
- interpretation
- searchTerms

## 1. sourceText

sourceText 是古籍原文，不允许：

- 修改
- 补写
- 改写
- 重新翻译后冒充原文

最终必须使用输入数据中的 sourceText。

## 2. symbols

提取梦境中的核心对象。

例：

原文：
龙蛇入门主得财

symbols：
["龙", "蛇"]

原文：
齿自落者父母凶

symbols：
["牙齿"]

原文：
日月初出家道昌

symbols：
["太阳", "月亮"]

要求：

- 使用现代用户容易理解的名称
- 一条可以有多个 symbol
- 不要把“得财”“大吉”“疾病”等结果当 symbol

## 3. situation

描述梦里实际发生了什么。

例：

龙蛇入门主得财
→ 龙或蛇进入门内

蛇咬人主得大财
→ 蛇咬人

齿自落者父母凶
→ 牙齿自己脱落

要求：

- 只描述梦境动作/状态
- 不包含吉凶解释
- 使用现代中文
- 尽量简短

## 4. interpretation

把古籍含义翻译成现代中文。

例：

蛇咬人主得大财

→
传统解梦中，梦见蛇咬人，被解释为可能与获得较多财物有关。

齿自落者父母凶

→
传统解梦中，梦见牙齿自行脱落，被视为与父母或长辈方面的不顺有关。

要求：

- 必须忠实于 sourceText
- 不增加原文没有的寓意
- 不说成现实必然发生
- 使用“传统解梦中”“被视为”“被解释为”等表达
- “凶”不能扩写成具体死亡、灾难、疾病
- “疾病”只能表达原文传统说法，不作医学判断

## 5. searchTerms

生成现代用户可能输入的检索词。

例：

蛇咬人：
[
  "蛇咬人",
  "被蛇咬",
  "蛇咬我",
  "梦见被蛇咬",
  "梦到蛇咬人"
]

要求：

- 3～8 个
- 必须与原文梦境本身相关
- 不添加原文没有的关键情境
- suggestions 可以作为参考，但不能盲目复制


## 6. symbols 严格规则

symbols 只能包含“梦境中实际出现或被直接描述的对象”。

禁止把古文解释结果放入 symbols。

例如：

天门开贵人荐引
正确：
symbols = ["天门"]

错误：
symbols = ["天门", "贵人"]

因为“贵人荐引”是解释结果，不是梦境内容。

以下类型通常属于结果，不得作为 symbols：
贵人、富贵、财、官职、官位、贵子、疾病、忧愁、兵荒、吉、凶、福、禄、寿命、公卿、王侯。

如果一个词只出现在古文后半段的吉凶解释中，不得作为 symbol。

## 7. situation 严格规则

situation 只能改写梦境本身，不解释结果。

不得为了让句子通顺而补充原文不存在的事件。

例如：

天明妇有生贵子

不要擅自改成：
“天亮时妇人怀孕”

应采用更保守表达，例如：
“梦见天明相关景象”

如果原文结构不够清晰，宁可保守，不要推断。

## 8. searchTerms 严格规则

searchTerms 必须只来源于 symbols + situation。

禁止使用 interpretation 中的结果词生成搜索词。

例如：

天门开贵人荐引

允许：
天门开
天门打开
梦见天门
梦见天门打开

禁止：
贵人相助
贵人引荐
升官
好运

searchTerms 不得重复。
## 9. interpretation 禁止预测式表达

即使加入“可能”，也不要写成现实事件将发生的句式。

禁止：

可能会有贵人引荐
可能会发财
可能会升官
可能会生贵子
可能会有疾病

推荐：

被解释为可能与贵人引荐有关
被视为与财物所得有关
被解释为与官职提升有关
被视为与生子相关
被解释为与疾病消除相关

核心原则：
只描述传统古籍如何解释这个梦，不预测现实未来。

## 12. symbols 可以为空

symbols 只用于明确出现在梦境中的人物、动物、物体、自然事物、地点等“对象”。

如果原文的梦境部分只有动作、行为或状态，没有明确对象，symbols 必须返回 []，不要为了填充字段而虚构对象。

例如：

远行出入命通达

正确：
symbols = []
situation = "远行出入"
interpretation = "传统解梦中，梦见远行出入，被解释为与命运通达有关。"
searchTerms = ["远行","出门远行","梦见远行","梦见出门远行"]

禁止为了填充 symbols 而生成：
["道路"]
["远方"]
["出入口"]

这些对象并没有出现在原文中。

另一个原则：
动作放 situation，不强行当 symbol。
